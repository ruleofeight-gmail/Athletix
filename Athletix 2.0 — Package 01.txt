Design goals for Package 1
1. Central bootstrap

Everything flows through:

athletix.php
        |
        ↓
Athletix_Loader
        |
        ↓
Athletix_Plugin
        |
        ↓
Registered Modules
2. Future modules plug in cleanly

Future systems will register like:

Athletix_Registry::register(
    'standings',
    Athletix_Standings_Engine::class
);

No more editing the main plugin file every time.

3. Events system

Instead of classes directly talking to each other:

Old:

Match Meta
    |
    ↓
Standings
    |
    ↓
Stats

New:

Match Saved

↓

Event Dispatcher

↓

Statistics Engine

↓

Standings Engine

↓

Rankings Engine
4. Configuration layer

Instead of:

get_option(
    'ax_sport_profiles'
);

everywhere:

New:

Athletix_Config::get(
    'sports'
);
5. Logging foundation

Future debugging:

Athletix_Logger::info(
    'Match processed',
    [
        'match_id'=>123
    ]
);
6. Cache foundation

Future optimization:

Athletix_Cache::remember(
    'league_table_5',
    function(){
        return $table;
    }
);
